# Agilex 27 Development Kit with HPS Enablement Expansion Board (OOBE)

Platform folder `dk-dev-agilex27-enablement` contains designs for the Agilex 27 Development Kit with
Out of Box Experience (OOBE) daughter card, which is also known as HPS Enablement Expansion Board.

Refer to the HPS Baseline System Example Design User Guide: Agilex 27 Development Kit (URL: TBD)
for Baseline System Example Design context.
